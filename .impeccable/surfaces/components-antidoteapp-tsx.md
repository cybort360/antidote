# ANTIDOTE case map

## Scope and mode

Persuade landing plus Operate case-map mode. `components/AntidoteApp.tsx` opens with a story-led landing experience, then enters the functional case-map shell and its five data views.

## Audience, task, proof, and constraints

Security operators and AI platform teams inspect an incident, trace causal influence, preview repair, execute repair, and review attack intelligence, trace, audit, and documentation. The live causal graph, inspector, recovery controls, and tested API behavior are the proof. Preserve all real product claims and make no unverified live-integration claim.

## Chosen direction and memorable moment

Forensic contact-sheet console. Basalt-black field, chartreuse command signal, oxidized-red contamination state, oversized stacked recovery statement, geometric containment sigil, and the graph as the central instrument. The memorable moment is a live causal field, where one poisoned memory routes a red pulse through agents, a decision, and an external action. Containment reverses the signal without deleting the chain, then leads into the live topology.

## Composition and fidelity inventory

| Ingredient | Medium | Commitment |
| --- | --- | --- |
| Wordmark and containment mark | semantic HTML and CSS geometry | Sharp chartreuse ruled mark, no raster logo needed. |
| Landing containment field | Canvas 2D plus semantic HTML and CSS | Pointer-aware causal scene with a static fallback. Red pulse traces contamination. Chartreuse pulse reverses on containment. |
| Causal topology | existing SVG and live scenario data | Interaction, focus states, real node types, animated contamination path, and repair preview stay functional. |
| Recovery commands | semantic HTML buttons | Simulate and execute actions stay primary and readable. |
| Status state language | semantic HTML and CSS | Chartreuse for trusted/runtime, red for active threat, amber for simulation, muted gray for repaired state. |
| Future incident imagery | generated raster, deferred | No fabricated evidence. Image prompts will be used only for optional ambient campaign imagery after core implementation. |

## Motion and responsive rules

Motion is stateful and optional: the landing causal scene traces active contamination, selected and blast-radius nodes use existing SVG rings, and reduced-motion disables animation. The Canvas requestAnimationFrame loop pauses offscreen and when the document is hidden. Desktop opens with the landing story field, call to action, then a trace-to-repair narrative and topology. Mobile stacks the wordmark, navigation, message, action, status, then topology without cropping the message.

## Open decisions

No imagery has been generated. The user requested image prompts after implementation.
