# ANTIDOTE case map

## Scope and mode

Operate mode. `components/AntidoteApp.tsx` is the case-map shell and its five functional data views.

## Audience, task, proof, and constraints

Security operators and AI platform teams inspect an incident, trace causal influence, preview repair, execute repair, and review attack intelligence, trace, audit, and documentation. The live causal graph, inspector, recovery controls, and tested API behavior are the proof. Preserve all real product claims and make no unverified live-integration claim.

## Chosen direction and memorable moment

Forensic contact-sheet console. Basalt-black field, chartreuse command signal, oxidized-red contamination state, oversized stacked recovery statement, geometric containment sigil, and the graph as the central instrument. The memorable moment is the opening declaration, “REVOKE THE MEMORY. REPAIR THE CONSEQUENCE.”, immediately followed by the causal topology.

## Composition and fidelity inventory

| Ingredient | Medium | Commitment |
| --- | --- | --- |
| Wordmark and containment mark | semantic HTML and CSS geometry | Sharp chartreuse ruled mark, no raster logo needed. |
| Hero containment field | semantic HTML and CSS geometry | Concentric circle, square threat geometry, and explanatory copy. |
| Causal topology | existing SVG and live scenario data | Interaction, focus states, real node types, animated contamination path, and repair preview stay functional. |
| Recovery commands | semantic HTML buttons | Simulate and execute actions stay primary and readable. |
| Status state language | semantic HTML and CSS | Chartreuse for trusted/runtime, red for active threat, amber for simulation, muted gray for repaired state. |
| Future incident imagery | generated raster, deferred | No fabricated evidence. Image prompts will be used only for optional ambient campaign imagery after core implementation. |

## Motion and responsive rules

Motion is stateful and optional: active contamination traverses its true graph edge, selected and blast-radius nodes use the existing SVG rings, and reduced-motion disables animation. Desktop opens with the hero field; mobile stacks the wordmark, navigation, recovery statement, telemetry, then topology without cropping the message.

## Open decisions

No imagery has been generated. The user requested image prompts after implementation.
